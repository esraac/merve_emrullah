Nasıl Yeni Link Alınır?

  1. GoogleAppsScript.js kodunu script.google.com'a yapıştırın.
  2. Yayınla (Deploy) -> Yeni yayınlama seçeneğine tıklayın.
  3. Erişim iznini "Herkes" (Anyone) yapıp Yayınla butonuna basın.
  4. Verilen Web App URL adresini yukarıdaki kutuya yapıştırıp kaydedin.
